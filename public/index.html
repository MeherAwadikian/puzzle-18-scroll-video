Scroll to Scrub the Animation

120 individually rendered PNG frames of a spinning icosahedron, drawn on a <canvas> element. There is no video and no CSS keyframe animation — each scroll-pixel position maps deterministically to one specific frame index.

That's the whole trick

The scroll track above is 500vh tall. While it scrolls past, the canvas is position: sticky so it stays pinned on screen. A scroll listener computes how far through that tall section you are (0 to 1), multiplies by 119, and draws the matching frame from the preloaded image array onto the canvas. Frames load progressively in the background — frame 0 is usable almost immediately, the rest stream in and the clamp simply holds the nearest loaded frame until it arrives.

Puzzle #18 — scroll-controlled image-sequence animation. Built with vanilla JS + Canvas 2D.
